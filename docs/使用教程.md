# OpenVPN 服务器（fnOS）使用教程

> 适用版本：v1.0.86（最新）  ·  适用系统：飞牛私有云 fnOS
> 本文介绍如何从零安装、初始化、管理客户端，并在手机 / 电脑上连接使用。

---

## 一、简介

OpenVPN 服务器是跑在飞牛私有云（fnOS）上的 **VPN 服务端应用**，让你在外出、用手机或异地电脑时，安全访问家里的 fnOS 与内网设备。

核心特点：

- **一键安装**：通过 fnOS 应用中心安装，安装过程不联网，以原生进程运行，由应用中心统一启停。
- **内置 Web 管理**：提供初始化向导、证书管理、在线客户端列表、在线编辑 `server.conf`、分组管理等。
- **多端连接**：手机（OpenVPN Connect）、Windows（OpenVPN GUI）、macOS（Tunnelblick / Viscosity）均可导入 `.ovpn` 配置连接。
- **移动端适配**：v1.0.86 修复了手机端登录成功不跳转的问题。

---

## 二、安装

1. 打开 fnOS **应用中心**。
2. 搜索 **OpenVPN**，找到「OpenVPN 服务器」应用。
3. 点击 **安装**，等待安装完成（安装不联网，耗时很短）。
4. 安装完成后，在桌面或应用列表中打开它。

![应用中心安装 OpenVPN](images/01-install.png)

---

## 三、初始化设置（首次打开）

首次打开会进入 **初始化向导**，按引导完成基础配置后即可使用。通常包括：

- **第 1 步 · 基础设置**：设置服务端口（默认 `1194`）、连接协议（UDP / TCP）、以及 **管理员密码**。
- **第 2 步 · 高级选项**：可开启 **IPv6 直连监听**（监听协议自动 tcp6/udp6 双栈，IPv4 客户端不受影响）。

完成后会自动进入登录页。

![初始化向导](images/02-init-wizard.png)

---

## 四、登录

进入应用首先看到登录页：

- **管理员**：使用初始化时设置的管理员密码登录，拥有证书管理、分组管理、设置等全部权限。
- **普通用户**：由管理员在后台创建的账户，通常只能下载自己的客户端配置、查看连接状态。

> **手机端注意（v1.0.86 修复）**：早期版本在手机端（fnOS App / 移动浏览器）登录提示「登录成功」后会停在登录页不跳转。v1.0.86 已修复，手机端登录后自动进入仪表盘。

![桌面端登录页](images/03-login.png)

![手机端登录后进入仪表盘](images/04-login-mobile.png)

## 五、仪表盘

登录后进入仪表盘，主要信息卡片：

- **服务器信息卡**：运行状态、运行时长（每 5 秒实时刷新）、版本与更新状态。
- **在线客户端列表**：当前已连接的客户端、分配的 IP、连接时长等，支持分页。
- **版本行**：显示当前版本与更新状态徽标，可静默检测更新。

![仪表盘总览](images/05-dashboard.png)

## 六、证书与客户端管理

在 **证书管理** 页可以管理所有 VPN 客户端：

1. **新建客户端**：生成专属证书 + 客户端配置（`.ovpn`）。
2. **导入配置**：导入已有的 `.ovpn`（适用于外部生成的客户端）。
3. **下载配置**：把生成的 `.ovpn` 下载到本地，用于导入手机 / 电脑客户端。
4. **吊销客户端**：吊销后该客户端将无法再连接。

![证书与客户端管理](images/06-cert.png)

![下载 .ovpn 配置](images/07-download-ovpn.png)

## 七、连接客户端

### 7.1 手机（OpenVPN Connect）

1. 在应用商店安装 **OpenVPN Connect**。
2. 将 `.ovpn` 配置文件传到手机，用 OpenVPN Connect **导入**（也可通过扫码 / 文件方式）。
3. 点击连接，状态显示 **已连接** 即成功。此时手机可通过 VPN 访问家中 fnOS 与内网。

![手机端已连接](images/08-connect-mobile.png)

### 7.2 Windows / macOS

- **Windows**：安装 **OpenVPN GUI**，右键托盘图标导入 `.ovpn` 并连接。
- **macOS**：使用 **Tunnelblick** 或 **Viscosity**，导入 `.ovpn` 连接。

![桌面端已连接](images/09-connect-desktop.png)

## 八、分组管理（进阶）

从 v1.0.76 起支持 **分组管理**，可为不同用户群体推送不同的网络策略：

- 创建分组，并配置该分组的 **路由（route）/ DNS / 重定向网关（redirect-gateway）/ 屏蔽外部 DNS（block-outside-dns）**。
- **分组 DNS 优先级**：当某分组的 CCD 配置中包含 DNS / 路由时，会先 `push-reset` 清空 `server.conf` 的全局 push，使分组 DNS 优先于全局默认 DNS 生效。

![分组管理](images/10-groups.png)

## 九、高级设置

在 **设置** 页可以进行更底层的管理：

- **server.conf 在线编辑**：直接在网页上编辑服务端配置，无需登录终端。
- **自定义 DNS**：设置页新增「主 DNS / 备 DNS」输入框，可覆盖默认的 `223.5.5.5 / 114.114.114.114`，留空则保持默认。
- **数据卷路径**：框架自动适配 `vol1 / vol2 / vol3` 任意部署，无需手动指定。
- **IPv6 直连监听**：开关控制是否启用 IPv6 监听（tcp6/udp6 双栈）。

![设置页](images/11-settings.png)

## 十、更新

有两种方式获取新版本：

1. **应用内检测更新**：fnOS 应用内「检测更新」会从更新源拉取最新版（当前最新 **v1.0.86**），点击即可更新。
2. **手动安装**：到 GitHub Releases 下载对应架构（x86 / arm）的 `.fpk`，在应用中心手动安装。

![应用内检测更新](images/12-update.png)

## 十一、常见问题（FAQ）

**Q1：手机端登录提示「登录成功」但停在登录页、不跳转？**
A：这是早期版本的已知问题，已在 **v1.0.86** 修复（移动端 webview 会静默丢弃 `location.assign()`，已改为 `window.location.href`）。请升级到 v1.0.86 或更新版本。

**Q2：客户端连不上？**
A：依次检查：① 路由器是否做了 `1194` 端口转发（UDP/TCP 与设置一致）；② fnOS 防火墙是否放行；③ `.ovpn` 中的协议 / 端口是否与服务器一致；④ 客户端证书是否已被吊销。

**Q3：数据卷路径报错 / 找不到路径？**
A：应用会自动适配 `vol1/vol2/vol3` 任意部署，正常情况下无需手动设置。若环境变量未注入，框架会兜底定位主数据卷 `vol1`。

**Q4：自定义 DNS 不生效？**
A：确认设置页填写了主 / 备 DNS；若使用了分组管理且分组 CCD 含 DNS，分组 DNS 会优先于全局默认 DNS 生效。
